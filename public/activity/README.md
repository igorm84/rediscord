# Activity artwork

`dead-by-daylight.png` is an unchanged 96×96 PNG downloaded from the official Dead by Daylight website:

https://deadbydaylight.com/icons/icon-96x96.png

It is displayed at 24×24 pixels, matching the original activity image dimensions. The local copy avoids a runtime dependency on the Google thumbnail URL previously used here, which now returns HTTP 404. The old thumbnail's bytes could not be recovered, so an exact visual match to that thumbnail cannot be confirmed. This is the official game's tally-mark artwork, replacing the generic controller icon introduced in PR #28.

Artwork and trademarks belong to Behaviour Interactive. Rediscord is an unofficial UI study.
